## 1. 链路状态怎样算出下一跳？

**距离向量交换「我到哪些目的地有多远」，链路状态通告「我和哪些邻居相连，链路代价是多少」。** 按作用范围分类，RIP、OSPF 和 IS-IS 都是域内协议。RIP 属于距离向量，OSPF 和 IS-IS 属于链路状态。BGP 是后面要学的域间路径矢量协议。

```text
Hello 发现邻居 → 生成并泛洪链路状态通告（LSA）
→ 各路由器用收到的通告拼出拓扑（LSDB）
→ 各自以自己为起点跑 Dijkstra → 记录到每个目的地的下一跳
```

手推一次：`A—B` 代价 1，`B—C` 代价 2，`A—C` 代价 5。A 算出去 C 的最小代价是 `1 + 2 = 3`，表里记 `C → B`。收到去 C 的包时，A 按表交给 B。

课件用四条条件解释路径选择的一致性：**拓扑一致、优化同一代价、链路代价为正、平局处理一致**。在同一张正权图上，沿最短路走一跳，到目的地的剩余代价就严格下降。拓扑变化时，有的路由器先换表，有的还用旧表，收敛期间仍可能短暂成环或走到死路。[官方教材：链路状态与收敛](https://textbook.cs168.io/routing/link-state.html)

## 2. 拼全图和泛洪的开销花在哪？

**开销在控制平面。** 泛洪占链路带宽，LSDB 占内存，更新最短路要用 CPU。数据平面转发时直接查已经算好的下一跳。

同一份通告可能绕不同路径到达。用**通告来源和版本号**区分内容，新版本更新 LSDB 并继续泛洪，重复或旧版本不再触发一轮泛洪。这样仍可能收到重复副本，但每收到一份就再转发的循环被打断。去重和可靠投递各有用途，后者仍可用确认、重传或定期刷新来处理丢包。OSPF 也会周期刷新 LSA，区域划分可以限制区域内拓扑信息的传播范围。[官方教材：避免无限泛洪](https://textbook.cs168.io/routing/link-state.html#avoiding-infinite-flooding) · [OSPF 规范：刷新与泛洪](https://www.rfc-editor.org/rfc/rfc2328.html#section-12.4)

## 3. CIDR 怎样省表项？

IPv4 有 32 位。CIDR 写作 `地址/前缀长度`，`/n` 固定前 `n` 位，整个地址块有 `2^(32−n)` 个地址。例如 `10.4.0.0/23` 覆盖 `10.4.0.0` 到 `10.4.1.255`，共 **512 个地址**。前缀长度可按需求选，分配越细，前缀就越长。

课件里一个网络的多台主机共用一个出口，我问这是不是「规约」。在转发表里可分成两种做法：

- **路由聚合**：`10.4.0.0/24` 和 `10.4.1.0/24` 恰好填满一个 `/23`。若两块都走 R2，可以用 `10.4.0.0/23 → R2` 代替两条。合并前要检查覆盖范围和下一跳，不能仅凭前几位看起来相同就把范围扩大。
- **默认路由**：`0.0.0.0/0` 匹配所有 IPv4 地址，在没有更具体匹配时兜底。例如主机把目的地址不在直连网络、也没有其他匹配路由的包交给默认网关。

有例外时保留一条更具体的路由。按**最长前缀匹配**，只在匹配的条目里选固定比特数最多的一条：

| 目的地址 | 匹配的前缀，从长到短 | 选哪个下一跳 |
| --- | --- | --- |
| `10.4.1.7` | `10.4.1.0/24`、`10.4.0.0/23`、`0.0.0.0/0` | `/24` 指定的 R3 |
| `10.4.0.7` | `10.4.0.0/23`、`0.0.0.0/0` | `/23` 指定的 R2 |
| `192.0.2.7` | `0.0.0.0/0` | 默认出口 |

**分配和转发是两件事。** 地址通常由 IANA 分配给区域互联网注册管理机构，再经 ISP 等分配给组织和用户。下级从上级的前缀中切出更长的前缀，这种结构便于汇总。实际网络如果有多出口，可能仍需发布更具体的路由。[官方教材：CIDR、聚合与多宿主](https://textbook.cs168.io/routing/addressing.html) · [IANA 地址分配说明](https://www.iana.org/numbers)

IPv6 把地址扩到 **128 位**，也能用 `/n` 表示前缀。十六进制各组可省略前导零，连续的全零组最多压缩一次，例如 `2001:0db8:0:0:0:0:0:1` 写成 `2001:db8::1`。[第 7 讲课件，第 53–55 页](https://docs.google.com/presentation/d/12Zl53GNXpSC-tXg8Jk5hKHCUrvukJ_PbG7fOhfe-7D0/htmlpresent)

## 回看时先做三道小题

1. 两条路径送来同一版本的 LSA，第二份要不要再泛洪？**不用。**
2. A 已经重算，B 还没换表，各自的最短路可能拼成环吗？**可能，因为使用了不同版本的拓扑。**
3. `/23` 和 `/24` 都匹配，是否比较链路代价来决定选哪条？**这一步先按前缀长度选 `/24`。**
